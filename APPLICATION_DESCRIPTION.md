# Application project description

**NEXORA | Customer Intelligence**  
Independent portfolio project · Python · Streamlit · Product Analytics · OpenAI API

I developed a fictional B2B SaaS customer-intelligence prototype to explore how product usage, license activation and engagement indicators can be brought together to help teams prioritize customer follow-up.

The application includes an interactive dashboard, account-level exploration, a transparent heuristic health index, rule-based next-step suggestions and an optional conversational AI assistant that answers questions about the filtered synthetic dataset.

The project was inspired by general themes I encountered in B2B software work, including usage indicators, customer monitoring, product performance, user support and QA. The implementation and data are entirely independent and synthetic; no employer or customer data is included.

**Important scope note:** the health index is illustrative and is not a validated churn prediction. Recommendations support human review; the app does not contact customers or update external systems.
